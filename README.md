# MURA MENASA FZCO corporate verification site

Standalone static website package for `2rh.org`.

## Purpose

Public corporate presence for MURA MENASA FZCO for corporate verification, Apple/Dun & Bradstreet review, counterparties and general company information.

## Architecture

- Static HTML/CSS.
- No JavaScript dependency.
- No PAPA runtime dependency.
- No database.
- No authentication.
- No analytics or external trackers.
- No external font/CDN dependency.
- No deployment or DNS changes are included in this package.

## Publication boundary

This package is implementation-only. Public hosting, DNS changes, TLS issuance and mail DNS changes require separate authorization.

## Contact-data boundary

Only confirmed corporate facts are published. Email, phone and detailed postal address are intentionally omitted until verified against controlled company records.
